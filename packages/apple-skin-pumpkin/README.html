AppleSkinPumpkin ​v0.1.0

The plugin syncs saturation and exhaustion so AppleSkin can show accurate food stats.

See the plugin guide and API reference on the documentation site.

Installation ​

Download apple-skin-pumpkin.wasm from the plugin's GitHub release, put it in your server's plugins/ folder, and restart Pumpkin. On the first load, a full restart lets Pumpkin ask for the plugin's permissions; hot reload cannot prompt for them.

How it works ​

Vanilla tells a client about saturation only when it reaches zero, and never sends exhaustion at all, which leaves the food tooltips AppleSkin draws behind by a tick. So the plugin reads every online player once per tick and sends the two values, plus whether the world heals players by food. It sends only what moved since the last packet, so a still player costs nothing.

AppleSkin is a Java Edition mod, so Bedrock players are skipped.

Seeing what it does ​

Set log.level to debug in your Pumpkin config. Every packet the plugin sends is then logged with the player and the value, along with players joining, leaving and being skipped. Ticks where nothing changed are silent, which is the point of only sending on a change.

Permissions ​

Pumpkin asks you to approve these on the server console when it loads the plugin. It skips the question when the [plugins] table in pumpkin.toml lists all of them in allowed_permissions or sets ask_permission_confirmation = false. Pumpkin remembers your answer and asks again after the plugin file or this list changes.
