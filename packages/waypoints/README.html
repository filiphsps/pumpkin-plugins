Waypoints ​v0.1.0

Waypoints lets you create shared locations, control who can access each one, show them on a Java HUD, and look them up with PumpkinPIE placeholders.

See the plugin guide and API reference on the documentation site.

Overview ​

Waypoints stores shared named locations on the server. Each waypoint can have a display label, description, color, item icon, and optional HUD visibility range. Waypoints are restricted by default; operators can make them public or grant access to specific players, permission nodes, or permission-marker groups. Players can find and teleport to enabled waypoints they can access. Records have no creator ownership.

Installation ​

Download waypoints.wasm from the plugin's GitHub release, put it in your server's plugins/ folder, and restart Pumpkin. On the first load, a full restart lets Pumpkin ask for the plugin's permissions; hot reload cannot prompt for them.

Permissions ​

Pumpkin asks you to approve these on the server console when it loads the plugin. It skips the question when the [plugins] table in pumpkin.toml lists all of them in allowed_permissions or sets ask_permission_confirmation = false. Pumpkin remembers your answer and asks again after the plugin file or this list changes.

fs.read.dataRead the waypoint store from the plugin data folder.
fs.write.dataPersist waypoint changes in the plugin data folder.
