@pumpkin-plugins/tab-display API / plugin / Plugin

Abstract Class: Plugin ​

Defined in: tools/pumpkin-api/src/host-plugin.ts:45

Base class for a Pumpkin plugin.

Subclasses provide metadata and register their handlers with the context during onLoad.

Example ​

typescript
import { Plugin, registerPlugin } from '@pumpkin-plugins/pumpkin-api';

class ExamplePlugin extends Plugin {
    metadata() {
        return {
            name: 'example', version: '1.0.0', authors: ['Example'],
            description: 'An example plugin', dependencies: [], permissions: []
        };
    }
}

registerPlugin(new ExamplePlugin());

registerEvent<T>(context, eventType, handler, priority?, blocking?): void

Defined in: tools/pumpkin-api/src/core.ts:129

Register an event callback with the Pumpkin server.

Type Parameters ​

Event discriminator that determines the callback payload.

Parameters ​

context ​

Context

Plugin context used to register the handler.

eventType ​

T

Event to receive.

handler ​

EventHandler<EventPayload<T>>

Callback for the event payload.

priority? ​

EventPriority = 'normal'

Dispatch priority; defaults to normal. It can only order handlers within the blocking or non-blocking group. Pumpkin 0.2.0+26.3-26.51 stores it but does not sort by it, so handlers in a group run in registration order.

blocking? ​

boolean = true

Whether Pumpkin applies the payload the handler returns; defaults to true. Pumpkin runs every blocking handler before any non-blocking one and ignores what non-blocking handlers return, so only blocking handlers can modify or cancel the event.

Returns ​

void

Remarks ​

The event type determines the payload type accepted by the callback.
