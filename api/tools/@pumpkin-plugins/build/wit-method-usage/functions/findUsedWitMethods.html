@pumpkin-plugins/build API / wit-method-usage / findUsedWitMethods

Function: findUsedWitMethods() ​

findUsedWitMethods(__namedParameters): UsedWitMethods | undefined

Defined in: tools/build/src/wit-method-usage.ts:44

Select WIT operations referenced by the files esbuild bundled into the plugin.

Dynamic keys retain every possible member. An input that is not a file on disk, such as a module generated by another esbuild plugin, cannot reveal its host calls, so the result is undefined to request full native adapters. Dynamic event registrations set eventTypes to undefined so callers retain every event converter.
