@pumpkin-plugins/port-mapping API / mapper / PortMapper

Class: PortMapper ​

Defined in: tools/port-mapping/src/mapper.ts:98

Keeps a set of ports open on the router: finds the router, opens each port, renews it before the lease ends and closes it when it is released. When this machine already has a public address nothing is opened. Driven by tick, one network operation at a time.
