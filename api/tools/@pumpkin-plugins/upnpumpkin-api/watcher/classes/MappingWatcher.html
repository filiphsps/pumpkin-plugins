Class: MappingWatcher ​

Defined in: tools/apis/upnpumpkin-api/src/watcher.ts:14

Keeps asking UPnPumpkin about one port and tells you when the answer changes. It copes with UPnPumpkin loading after your plugin, being reloaded, or not being installed at all.
