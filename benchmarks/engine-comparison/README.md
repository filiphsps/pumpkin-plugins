# @pumpkin-plugins/engine-comparison

Private real-server comparison of QuickJS and Static Hermes plugin builds. Run unit tests with
`pnpm --filter @pumpkin-plugins/engine-comparison test` and the three-engine Pumpkin comparison with
`pnpm --filter @pumpkin-plugins/engine-comparison compare-engines`.

See the [benchmarking guide](../../docs/benchmarking.md) for workloads, report details, and how to
interpret results.
