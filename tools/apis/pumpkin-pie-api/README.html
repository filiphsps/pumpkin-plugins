@pumpkin-plugins/pumpkin-pie-api ​

Host-independent TypeScript client, expansion router and recovery session for PumpkinPIE (EXTERNAL) protocol 0.

PumpkinPIE is an external, separately installed placeholder-provider plugin. Its implementation and build tooling live in the upstream repository, which publishes provider downloads through its releases. This workspace package provides the client API; it does not build or bundle the provider.

See the guide for package usage and lifecycle details.

Quick start ​

With the upstream provider loaded, inject ipcSend, negotiate compatibility, and resolve text:

ts
import { PieClient } from '@pumpkin-plugins/pumpkin-pie-api';
import { ipcSend } from '@pumpkin-plugins/plugin-kit/ipc';

const pie = new PieClient(ipcSend);
pie.ping();
const line = pie.resolve('Hello %player_name%', 'Steve');
// line.text contains the resolved text; line.unresolved lists identifiers left unchanged.

Steve is the subject's current online player name. Catch provider failures at your plugin's boundary and choose its fallback presentation. For recurring work or contributed placeholders, use one shared PieSession per plugin.

See the guide for value lookups, batches, session and expansion lifecycle, and deterministic tests.
