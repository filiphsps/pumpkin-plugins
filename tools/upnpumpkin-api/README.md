# @pumpkin-plugins/upnpumpkin-api

The messages, a client and a watcher other plugins use to ask UPnPumpkin to make a port reachable from the internet.

This package is internal to the repository and is not published to npm. See the
[port forwarding guide](../../docs/port-forwarding.md) and [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/upnpumpkin-api/).
