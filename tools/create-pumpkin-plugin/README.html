create-pumpkin-plugin ​

Create a minimal standalone Pumpkin plugin in TypeScript or JavaScript.

sh
pnpm create pumpkin-plugin my-plugin

In a terminal, the command prompts for TypeScript or JavaScript. Use a language flag for scripts and CI:

Package managerInteractiveTypeScriptJavaScript
pnpmpnpm create pumpkin-plugin my-pluginpnpm create pumpkin-plugin my-plugin --tspnpm create pumpkin-plugin my-plugin --js
npmnpm create pumpkin-plugin my-pluginnpm create pumpkin-plugin my-plugin -- --tsnpm create pumpkin-plugin my-plugin -- --js
Yarn Classicyarn create pumpkin-plugin my-pluginyarn create pumpkin-plugin my-plugin --tsyarn create pumpkin-plugin my-plugin --js
Yarn Modernyarn dlx create-pumpkin-plugin my-pluginyarn dlx create-pumpkin-plugin my-plugin --tsyarn dlx create-pumpkin-plugin my-plugin --js
Bunbun create pumpkin-plugin my-pluginbun create pumpkin-plugin my-plugin --tsbun create pumpkin-plugin my-plugin --js

These launch forms follow the official pnpm create, npm init, Yarn Classic create, Yarn Modern CLI migration guide, and Bun create references.

Add --skip-install to create the files without installing packages. Existing destinations are rejected and left untouched. When launched by a supported package manager, the creator uses it to install dependencies. If it cannot detect one, it prints pnpm commands. Generated projects do not include the monorepo's plugin-kit scaffold.

The TypeScript template uses src/plugin.ts. The JavaScript template uses src/plugin.js, JSDoc types and checkJs. Both generate guest declarations from the API package's WIT using pumpkin-plugins-build --types-only before typechecking.
