# @pumpkin-plugins/config

Declares a plugin's settings as a schema and derives the default `config.toml`, the validation, the upgrades and the README table from it.

This package is internal to the repository and is not published to npm. See the
[plugin config guide](../../docs/plugin-config.md) and [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/config/).
