# @pumpkin-plugins/wasi-capabilities

[![npm downloads](https://img.shields.io/npm/dt/%40pumpkin-plugins%2Fwasi-capabilities)](https://www.npmjs.com/package/@pumpkin-plugins/wasi-capabilities)
[![latest npm release](https://img.shields.io/npm/v/%40pumpkin-plugins%2Fwasi-capabilities?label=latest%20release)](https://www.npmjs.com/package/@pumpkin-plugins/wasi-capabilities)
[![npm license](https://img.shields.io/npm/l/%40pumpkin-plugins%2Fwasi-capabilities)](https://www.npmjs.com/package/@pumpkin-plugins/wasi-capabilities)

Shares the WASI capability names, interface mapping and pinned WASI version used by the Pumpkin
builder and migration codemod. It has no runtime dependencies.

```ts
import { type Capability, capabilitiesForInterface } from '@pumpkin-plugins/wasi-capabilities';

const capability: Capability = 'http';
const candidates = capabilitiesForInterface('sockets/network'); // ['sockets', 'udp']
```

Pass an exact `package/interface` path without the `wasi:` prefix or `@version` suffix. A single
result is unambiguous; multiple results require review, and an empty array means the path is unknown.
