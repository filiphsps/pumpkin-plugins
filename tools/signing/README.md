# @pumpkin-plugins/signing

Signs and verifies plugin `.wasm` files in the format Pumpkin checks (Ed25519 over the module and a `pumpkin.metadata` section).

This package is internal to the repository and is not published to npm. See the
[CI and releases guide](../../docs/ci-and-releases.md) and [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/signing/).
