Host-independent TypeScript client, expansion router and recovery session for
[PumpkinPIE](https://github.com/Rennex07/PumpkinPIE) protocol 0.
<!-- docs:end overview -->

PumpkinPIE is the separately installed placeholder provider. Get its plugin and upstream
documentation from the [PumpkinPIE repository](https://github.com/Rennex07/PumpkinPIE);
see [upstream releases](https://github.com/Rennex07/PumpkinPIE/releases) for provider downloads.

Private workspace package; see the [guide](docs/index.md).

## Quick start

With the upstream provider loaded, inject `ipcSend`, negotiate compatibility, and resolve text:

```ts
import { PieClient } from '@pumpkin-plugins/pumpkin-pie-api';
import { ipcSend } from '@pumpkin-plugins/plugin-kit/ipc';

const pie = new PieClient(ipcSend);
pie.ping();
const line = pie.resolve('Hello %player_name%', 'Steve');
// line.text contains the resolved text; line.unresolved lists identifiers left unchanged.
```

`Steve` is the subject's current online player name. Catch provider failures at your plugin's
boundary and choose its fallback presentation. For recurring work or contributed placeholders,
use one shared `PieSession` per plugin.

See the guide for [value lookups](docs/index.md#look-up-one-value),
[batches](docs/index.md#resolve-several-subjects),
[session and expansion lifecycle](docs/index.md#consumer-and-expansion-lifecycle),
and [deterministic tests](docs/index.md#testing-and-provenance).
