# @pumpkin-plugins/port-mapping

Opens ports on a router with UPnP and NAT-PMP, written as tick-driven steps over a small `Network` interface so it runs inside a game tick.

This package is internal to the repository and is not published to npm. See the
[port forwarding guide](../../docs/port-forwarding.md) and [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/port-mapping/).
