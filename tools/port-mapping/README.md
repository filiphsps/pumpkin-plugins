# @pumpkin-plugins/port-mapping

Opens ports on a router with UPnP and NAT-PMP, written as tick-driven steps over a small `Network` interface so it runs inside a game tick.

An internal package of [pumpkin-plugins](https://github.com/filiphsps/pumpkin-plugins): it is not
published to npm, and the plugins in this repo use it as a workspace dependency. See [the docs](../../docs/port-forwarding.md)
for how it is used, and the [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/port-mapping/)
on the documentation site.
