# @pumpkin-plugins/test-harness

Starts a real Pumpkin server in a temporary folder with your plugins loaded, for integration tests in vitest.

An internal package of [pumpkin-plugins](https://github.com/filiphsps/pumpkin-plugins): it is not
published to npm, and the plugins in this repo use it as a workspace dependency. See [the docs](../../docs/testing.md)
for how it is used, and the [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/test-harness/)
on the documentation site.
