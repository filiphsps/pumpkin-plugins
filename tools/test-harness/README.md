# @pumpkin-plugins/test-harness

Starts a real Pumpkin server in a temporary folder with your plugins loaded, for integration tests in vitest.

This package is internal to the repository and is not published to npm. See the
[testing guide](../../docs/testing.md) and [API reference](https://filiphsps.github.io/pumpkin-plugins/api/tools/@pumpkin-plugins/test-harness/).
